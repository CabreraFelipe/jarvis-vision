# Motor de voz neuronal opcional — preparación V0.6

Fuentes consultadas: https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/CLI.md y https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/LICENSING.md; código CLI inspeccionado en commit 6aacdbc98eda4b1cb81d960bef7c7fae710b13fd (src/piper/__main__.py). Motor GPL-3.0-or-later; voces tienen condiciones separadas y cadena de corpus. No se incorpora código del motor ni se redistribuyen voces. Instalación opcional separada, seleccionar modelo local fiable con licencia revisada. No instalar automáticamente ni asumir voz comercialmente redistribuible. El candidato usa CLI aislada, texto UTF-8 por stdin y PCM por stdout, sin archivos de audio generados, servidor, ni descarga. El sistema anterior sigue por defecto, la escucha permanece desactivada salvo opt-in. Si Piper falla, muestra error y permite volver a Sistema; no duplica audio automáticamente. Persistencia separada de preferencias; no toca memoria ni cámaras. Límite de texto 4000 caracteres, timeout de síntesis 90 s, comprobación de tamaño PCM después de la captura (no es sandbox de modelos). La ejecución por respuesta puede aumentar latencia; requiere medición física y un motor/modelo real antes de activar por defecto. No se integra Pipecat en este bloque. Las pruebas usan simulaciones, no garantizan sonido ni calidad real.

Reintegrado sobre la base V0.5.4 y Whisper tras conflicto de ramas. La síntesis se ejecuta mediante Shutdown.start, conservando cierre acotado y gestor revisión 2. La configuración de entrada y salida permanece separada. No cambia cámaras ni motor de activación. Pendiente CI combinada y prueba física.

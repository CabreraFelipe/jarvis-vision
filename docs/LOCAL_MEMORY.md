# Memoria local — primer incremento
Notas explícitas en jarvis_memory.sqlite3 junto a los datos de usuario, no en el directorio versionado. Uso desactivado por defecto. Cuatro estilos de respuesta, alta/baja de notas y borrado total. No se guardan conversaciones, audio ni imágenes; no se extraen recuerdos automáticamente. No hay cifrado a nivel de aplicación: no introducir secretos; el borrado lógico no garantiza borrado forense ni de copias externas. El contexto está acotado a 1800 caracteres de notas y usa las más recientes, no búsqueda semántica. Al cambiar configuración se limpia el contexto de sesión y se descartan respuestas en curso, aunque no se cancela una inferencia ya enviada a Ollama local. El flujo sin contexto de sesión no adjunta recuerdos. No se cambia VERSION hasta validar el canal V0.4.4 en el PC. No hay dependencias nuevas.

# Transcripción local experimental
Faster-Whisper vía API local (https://github.com/SYSTRAN/faster-whisper), modelo multilingüe small (https://huggingface.co/Systran/faster-whisper-small). CPU int8, español explícito, VAD, tokenizer local, PCM en RAM. Resampleo con scipy. No instalar paquetes ni descargar modelos automáticamente. Las dependencias y modelo se obtienen separadamente. Pruebas simuladas; no se ha probado modelo real, precisión, latencia o memoria del PC. Se mantiene Vosk como predeterminado y activación continua separada, sin cambiar cámara, gestor, cierre o memoria. Action camera en pausa por problema del dispositivo informado por usuario.

Se añade alternativa explícita de activación por Whisper sobre segmentos de voz, no un detector acústico dedicado. Umbral fijo inicial, pausas y límite de captura, micrófono cerrado durante inferencia; sin mediciones físicas. El modo anterior se conserva por defecto y no se cambia automáticamente por seleccionar Whisper manual. Pruebas de segmentación, rechazo de voz sin activación y despacho. La ventana del comando continúa dependiendo de WakeCommand; una inferencia lenta puede consumir la ventana. No se garantiza respuesta inmediata.

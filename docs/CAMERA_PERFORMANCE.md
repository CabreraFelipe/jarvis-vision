# Corrección de rendimiento de cámaras

Observación física: webcam Redragon de 30 FPS nominales según el usuario; Windows Cámara fluida, JARVIS 1920x1080 a 5 FPS y 480p a menos de 20. No se conoce modelo exacto. Se elimina la selección automática exclusivamente por píxeles, midiendo lecturas exitosas tras calentamiento, probando ambos controladores y formatos antes de bajar resolución. Umbral heurístico 85% del FPS solicitado. Se ofrece selección manual de backend y perfiles Automática (equilibrado), Auto fluidez y Auto calidad. Los índices pueden cambiar entre controladores: comprobar la imagen, seleccionar manualmente si es necesario. No abrir índices adicionales. Las pruebas simuladas no garantizan FPS físicos. El sondeo puede aumentar tiempo de conexión y una llamada del driver puede bloquear. Se mantiene el fotograma original para IA/foto; la vista reduce antes de convertir colores, evita repetir render y muestra tasas separadas. No modifica el gestor ni versiones instaladas. Objetivo físico: verificar captura y vista en 1080p/30, ambos backends si necesario, dos cámaras, YOLO y restauración.

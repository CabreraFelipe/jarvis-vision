# JARVIS Vision

Asistente personal de IA para Windows: visión multicámara, voz en español, reconocimiento de objetos y conversación local con Ollama.

## Estado de distribución

V0.4.2: gestor local de actualizaciones. V0.4.3: importación inicial y validación del canal de GitHub Releases pendientes. No hay una release validada anunciada en este documento.

## Privacidad

Este repositorio público contiene exclusivamente código y documentación del programa. No subir configuraciones personales, capturas, conversaciones, credenciales ni modelos. JARVIS es independiente de Asia 2027.

Las actualizaciones requieren confirmación local. No habilitar instalación desatendida; la verificación independiente de firmas es una etapa posterior.
